ABOUT THE PROJECT

Araneta Lost & Found

Araneta Lost & Found is a personal full-stack web development project built using Angular for the frontend and Node.js with Express.js for the backend. It uses MongoDB for database management and Cloudinary for image storage. The project was created as a learning experience to explore full-stack web development and provide a more organized way to report, browse, and claim lost belongings. It is intended to be shared on GitHub as part of my development portfolio.

01

What Is This Project About?

The idea and inspiration behind the system.

Araneta Lost & Found is a personal project created as part of my journey in learning Angular and developing full-stack web applications.

I chose this project because I wanted to build something different from the usual practice projects while addressing a problem I have noticed in real life.

At De La Salle Araneta and even in climbing gyms, many belongings such as tumblers, shoes, books, bags, and other personal items are frequently left behind. Unfortunately, people sometimes forget about their belongings or never return to claim them.

Meanwhile, school and facility management have limited storage space for these items. As a result, unclaimed belongings may remain in storage for long periods or eventually be disposed of or given away.

This project aims to provide a more organized way to report lost belongings, turn in found items, and help owners identify and reclaim their property.

02

Current Functions

Features currently available in the system.

01

Report Lost Items

Users can submit details about belongings they have lost to help identify them if they are found.

02

Report Found Items

Users can register items they have found and receive a Turnover Code to use when handing the item to authorized staff.

03

Browse Found Items

Users can browse available found-item reports and check whether their missing belongings have been reported.

04

Submit Claims

Users can submit a claim for a found item by providing ownership details and a digital signature.

05

Track Claims

Users can check the progress of their claims using their Claim Reference Number.

06

Admin Dashboard

Administrators can manage lost reports, found reports, submitted claims, and returned items in one place.

07

Storage Location Management

Administrators can record cabinet and shelf locations to keep track of where found items are stored.

08

Claim Verification

Administrators can review submitted ownership claims, approve valid claims, or reject claims with an explanation.

09

Return Documentation

Administrators can record when an item has been successfully returned to its rightful owner.
