# lost-and-found-system

Araneta Lost & Found is a full-stack web-based Lost and Found Management System designed to help users report lost belongings, submit found-item reports, and claim recovered items.

The system features a user-friendly interface and an administrative dashboard for managing lost reports, found items, claims, and returned belongings.

### Technologies Used
- **Frontend:** Angular, HTML, CSS, TypeScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Image Storage:** Cloudinary

### Current Deployment Status

The frontend is publicly accessible through GitHub Pages as a project demonstration.

**Please note:** The live website is currently a frontend-only deployment. It is not connected to the backend server or MongoDB database. Therefore, database-dependent features such as submitting reports, retrieving records, processing claims, and administrative operations are not fully functional in the live version.

The backend and database components are part of the project's full-stack implementation but are not currently hosted.

### Purpose

Araneta Lost & Found is a personal full-stack web development project built using Angular for the frontend and Node.js with Express.js for the backend. It uses MongoDB for database management and Cloudinary for image storage. The project was created as a learning experience to explore full-stack web development and provide a more organized way to report, browse, and claim lost belongings. It is intended to be shared on GitHub as part of my development portfolio.
